3. Instrucciones para Inyección de Defecto Deliberado (Tabla 5 Rúbrica)

Para verificar que la suite de pruebas es estricta y falla ante regresiones deliberadas:

Opción 1: Defecto en Pruebas Unitarias (CU-005):

En backend/messenger/models.py, dentro de la clase ConversationMember, agregue el método:

def save(self, *args, **kwargs):
    self.role = 'admin'
    super().save(*args, **kwargs)

Ejecute python manage.py test messenger. El test unitario test_conversation_member_role fallará con AssertionError: 'admin' != 'member'.

Opción 2: Defecto en Pruebas de Integración (CI-007):

En backend/messenger/views.py, dentro de GroupConversationCreateView.post, comente la verificación de rol:

# if not is_admin_or_manager and not request.user.is_staff:
#     return get_failed_response(message='Solo administradores...', status_code=status.HTTP_403_FORBIDDEN)

Ejecute python manage.py test messenger. El test test_create_group_forbidden_for_regular_user fallará con AssertionError: 201 != 403.
